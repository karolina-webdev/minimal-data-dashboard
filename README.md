# Minimal Data Dashboard

A clean and minimalist data dashboard built with HTML, CSS and JavaScript.

The project displays a list of people and allows:
- filtering by city
- filtering by age (over 25)
- sorting by name
- sorting by age
- dynamic table rendering

## Technologies used
- HTML (page structure)
- CSS (minimalist styling)
- JavaScript (arrays, objects, filtering, sorting, DOM manipulation)

## What I learned
- How to store and work with data in arrays and objects
- How to filter and sort data in JavaScript
- How to update the DOM dynamically
- How to structure a small front‑end project

This project was created as part of my junior web development practice.
